Tools provides model tool factories and installable host state. Use it for todos,
thread goals, user questions and explicit spending consent. Factories run in the
host action with core's fenced ToolContext. Installed queries, mutations and
tables run in the host Convex app. This module owns no component.

## Wire it into agevex

Install the [built package and peers](/docs/getting-started). There is no module
convex.config mount. Start the docs site or replace the registry origin, then
install the stateful tools you need:

```sh title="Host app"
bunx shadcn add http://localhost:3000/r/todo.json
bunx shadcn add http://localhost:3000/r/goals.json
```

Merge their tables into the host schema and run `bunx convex dev` to generate
state references. The [registry guide](/docs/registry) covers install details.

```ts title="convex/schema.ts"
import { defineSchema } from "convex/server";
import { todoTables } from "./agevexTools/todoSchema.js";
import { goalTables } from "./agevexTools/goalsSchema.js";

export default defineSchema({ ...todoTables, ...goalTables });
```

Define the tool bag:

```ts title="convex/toolset.ts"
import {
  createTodoTools,
  createGoalTools,
  createAskUserTool,
  createContinueBudgetTool,
} from "agevex/tools";
import { internal } from "./_generated/api.js";
import type { ToolSet } from "ai";

export const tools: ToolSet = {
  ...createTodoTools(internal.agevexTools.todoState),
  ...createGoalTools(internal.agevexTools.goalsState),
  ask_user: createAskUserTool(),
  continue_budget: createContinueBudgetTool(),
};
```

Replace `convex/agents.ts` from getting started. Reuse the policies and refs
in `agentConfig.ts`, and register a root with the tools:

```ts title="convex/agents.ts"
import { Agent, registerAgent } from "agevex";
import { createOpenRouter } from "@openrouter/ai-sdk-provider";
import { components } from "./_generated/api.js";
import { registration } from "./agentConfig.js";
import { tools } from "./toolset.js";

const openrouter = createOpenRouter({ apiKey: process.env.OPENROUTER_API_KEY });
const main = new Agent(components.agent, {
  name: "Main",
  languageModel: openrouter.chat("openrouter/free", { usage: { include: true } }),
  instructions: "Use tools to track work and ask for missing information.",
  tools,
});
export const runtime = registerAgent(components.agevex, {
  ...registration,
  agents: [main],
});
export const { runTurn, coordinate, textTask } = runtime.internalFunctions();
export const {
  open,
  send,
  cancel,
  respond,
  answer,
  messages,
  streams,
  activity,
  runTree,
  delegations,
} = runtime.authorizedEndpoints();
```

There is no tools slot. Register `continue_budget` on roots only and install
its [consent state and approve/resume wrappers](/docs/tools/continue-budget)
before offering that flow.

## Tool behavior

| Item                                           | Model API                                | Host state                                    |
| ---------------------------------------------- | ---------------------------------------- | --------------------------------------------- |
| [Todo](/docs/tools/todo)                       | `todo_write({ todos })`, `todo_read({})` | One list per owner/thread                     |
| [Goals](/docs/tools/goals)                     | `goal_set({ goal })`, `goal_check({})`   | One goal per owner/thread                     |
| [Ask the user](/docs/tools/ask-user)           | `ask_user({ question })`                 | No item table; core records the deferred call |
| [Continue budget](/docs/tools/continue-budget) | `continue_budget({ reason })`            | Single-use, run-bound host consent            |

Answer deferred questions through core `answer`. Answer approvals through
core `respond`; a native-only response does not wake the managed turn.
Effects use once-tool receipts. Owner/thread facts come from ToolContext, never
model input. Public wrappers must authorize callers before internal state calls.

## Limits

| Item                      | Bound                                         |
| ------------------------- | --------------------------------------------- |
| Todo list                 | 100 items, 32 KiB serialized UTF-8 total      |
| Todo id / text            | 100 / 4,000 characters                        |
| Goal                      | 1–4,000 trimmed characters                    |
| Question / consent reason | 1–2,000 trimmed characters                    |
| Consent approval id       | 512 UTF-8 bytes                               |
| State cleanup             | 128 deletions plus one lookahead row per call |

Host state outlives threads. Call each internal cleanup until `done`; no cleanup
reschedules itself. Consent retention outlasts core receipt replay. A failed,
duplicate or rejected budget-resume send throws and rolls back consent spending,
budget changes and cancellation. Unknown paid outcomes never retry automatically.
See the [module README](https://github.com/pixelscortex/agevex/blob/HEAD/src/modules/tools/README.md).
