title: Tools
description: A stateless deferred question factory.
status: Available
---

```ts
import { createAskUserTool } from "agevex/tools";
const tools = { ask_user: createAskUserTool() };
```

The factory has no `execute`: core records a pending native call, validates the
owner's answer, and resumes. [Ask the user](/docs/tools/ask-user) documents the
2000-character default question, structured forms and per-agent policy.

The implementation is `src/modules/tools/client/ask_user.ts`, exported through
`client/index.ts`. It adds no tables, schemas or registry installation.
