Telemetry observes AI SDK calls and exports bounded OTLP JSON. Use it for model,
step and tool traces. It runs entirely in the host action. It owns no Convex
component, tables, transcript reader or durable outbox.

## Wire it into agevex

Install the [built package and peers](/docs/getting-started). There is no extra
package or convex.config mount. Set `LANGFUSE_PUBLIC_KEY`,
`LANGFUSE_SECRET_KEY` and `LANGFUSE_BASE_URL` in the host environment.

Replace `convex/agents.ts` from getting started, keeping its `agentConfig.ts`:

```ts title="convex/agents.ts"
import { registerAgent } from "agevex";
import { components } from "./_generated/api.js";
import { registration } from "./agentConfig.js";
import { langfuse, telemetry } from "agevex/telemetry";

export const runtime = registerAgent(components.agevex, {
  ...registration,
  telemetry: telemetry.slot({
    exporters: [
      langfuse({
        baseUrl: process.env.LANGFUSE_BASE_URL!,
        publicKey: () => process.env.LANGFUSE_PUBLIC_KEY!,
        secretKey: () => process.env.LANGFUSE_SECRET_KEY!,
      }),
    ],
  }),
});
export const { runTurn, coordinate } = runtime.internalFunctions();
export const {
  open,
  send,
  cancel,
  respond,
  answer,
  messages,
  streams,
  activity,
  runTree,
  delegations,
} = runtime.authorizedEndpoints();
```

Core supplies server-derived facts and an opaque turn key. Each key owns an
isolated buffer, flushed in `finally` with cancellation/deadline propagation.
For Braintrust, use `braintrust({ apiKey, projectId })` instead of Langfuse.

Keys (`publicKey`, `secretKey`, `apiKey`) take a string or a getter
(`() => string | Promise<string>`). A getter is called at each export, never at
construction, so hosts that forbid reading env at module load can pass
`() => process.env.X!`. Literal keys are validated when you construct the
exporter; a getter's value is validated when it resolves, and an empty or
oversized one sends nothing (exports fail open).

## Direct AI SDK calls

Create a fresh buffer for each turn. Consume the stream before flushing:

```ts title="convex/tracedTurn.ts"
import { streamText, type LanguageModel } from "ai";
import { telemetry, type Facts, type Exporter } from "agevex/telemetry";

export async function tracedTurn(
  model: LanguageModel,
  prompt: string,
  facts: Facts,
  exporters: Exporter[],
) {
  const trace = telemetry({ exporters });
  try {
    const result = streamText({
      model,
      prompt,
      maxRetries: 0,
      telemetry: { integrations: [trace.integration(facts)] },
    });
    await result.consumeStream();
    return await result.text;
  } finally {
    await trace.flush();
  }
}
```

Facts contain `subject`, `rootThreadId`, `threadId`, `runId`, `agent`
and `turnKey`. Empty facts throw; facts over 256 UTF-8 bytes export as digests.

## Content and delivery

`recordInputs` and `recordOutputs` default to false. Enable explicitly
and supply `sanitize(value, attributeName)` to redact host data. Returning
undefined drops an attribute. SDK recording opt-outs still apply. Raw provider
error diagnostics are never recorded.

Export seals the buffer once; repeated flushes share its promise. Late callbacks
are ignored. Exporters run concurrently, fail open and make one attempt. Stable
ids preserve ancestry but action retries can export duplicates. There is no
durable delivery guarantee.

## Limits

| Bound                       | Fixed ceiling                               |
| --------------------------- | ------------------------------------------- |
| Spans per turn              | 128 across all integrations                 |
| Encoded attributes per span | 16 KiB                                      |
| Value / key                 | 4 KiB                                       |
| Name / fact                 | 256 UTF-8 bytes; oversized facts are hashed |
| Configuration strings       | 4 KiB                                       |
| Exporters                   | 4 concurrent                                |
| Value traversal             | 128 nodes, depth 8                          |
| Export deadline             | 3 seconds, or core's supplied signal        |
| Complete request            | Less than 2.25 MiB                          |

Synchronous sanitizers and exporters must return control for timers to run.
Langfuse accepts HTTP(S) base URLs without embedded credentials, query or fragment;
Braintrust uses its US OTLP endpoint. See the
[module README](https://github.com/pixelscortex/agevex/blob/HEAD/src/modules/telemetry/README.md).
