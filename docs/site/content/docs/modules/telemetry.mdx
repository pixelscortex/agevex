`telemetry({ integration, flush? })` from `agevex/telemetry` returns the core
`TelemetrySlot`. Supply an AI SDK 7 `Telemetry` object or a synchronous
`(facts: TelemetryFacts) => Telemetry` factory. The factory receives trusted
`subject`, `rootThreadId`, `threadId`, `runId`, `agent`, `turnKey`, and optional
`purpose` / `nodeId`. Every forwarded callback also has these frozen facts on
`event.agevex`, replacing any content-supplied attribution.

The adapter catches synchronous throws, rejected callback promises, failed
getters, factory failures and flush errors. Model/tool execution wrappers share
one execution promise, so exporter failure cannot repeat paid work or hide its
underlying error. The adapter owns no spans, encoding, credentials or buffers.

## Host wiring with Braintrust

Install `braintrust` in your host, then use its AI SDK 7 integration. The example
uses the API shipped by Braintrust 3.40.0 (`braintrustAISDKTelemetry`,
`initLogger`, `withCurrent`). Select an exporter entry point supported by your
host runtime; if it needs Node, export `runTurn` from an action-only `"use node"`
module and keep mutations in a separate module. Test the exporter in that
runtime before enabling it. Credentials belong in the host environment.

```ts title="convex/hostTelemetry.ts"
import { braintrustAISDKTelemetry, initLogger, withCurrent, type Span } from "braintrust";
import type { Telemetry } from "ai";
import { telemetry } from "agevex/telemetry";

// Call inside the host action, where environment access is permitted.
export function createHostTelemetry() {
  const logger = initLogger({
    projectName: "my-agent-app",
    apiKey: process.env.BRAINTRUST_API_KEY!,
  });
  const turns = new Map<string, Span>();

  return telemetry({
    integration(facts) {
      let parent = turns.get(facts.turnKey);
      if (!parent) {
        parent = logger.startSpan({
          name: facts.agent,
          event: { metadata: { ...facts } },
        });
        turns.set(facts.turnKey, parent);
      }
      const span = parent;
      const sdk = braintrustAISDKTelemetry() as Telemetry;
      return {
        ...sdk,
        onStart: (event) => withCurrent(span, () => sdk.onStart?.(event)),
      };
    },
    async flush(facts) {
      const span = turns.get(facts.turnKey);
      turns.delete(facts.turnKey);
      span?.end();
      await logger.flush();
    },
  });
}
// Inside runTurn's action, construct the runtime with:
// registerAgent(components.agevex, { ...registration, telemetry: createHostTelemetry() })
// Invoke that runtime's runTurn handler using your host's existing action wiring.
```

The host's parent span holds the trusted attribution. Braintrust's operation
span starts in that parent's context and owns its model/tool children. Merely
passing `event.agevex` to an exporter does not guarantee it records custom
metadata: bind facts explicitly as this example does. agevex ships no Braintrust
or Langfuse exporter or dependency.

## Content and flushing

The host exporter owns input/output recording, redaction, span limits, delivery
and buffering. AI SDK 7 `TelemetryOptions` supports `recordInputs` and
`recordOutputs`; honor those flags in your integration. There is no agevex
content-recording policy or durable telemetry outbox.

Core calls `flush(facts, signal)` in `finally` and bounds it to three seconds,
even if the exporter ignores abort. Pass the signal to exporters that support
it. A direct call to the slot's `flush` has no separate deadline; the host must
bound it. Concurrent turns use distinct facts; keep any mutable buffers in the
host and key them by `turnKey`, deleting entries before awaiting export.
