## Wire it into agevex

Pass the slot to `registerAgent`; core supplies attribution and flushes each managed turn in `finally`.
No component mount is required.

```ts title="Managed turns → Langfuse OTLP"
import { registerAgent } from "agevex";
import { langfuse, telemetry } from "agevex/telemetry";

const runtime = registerAgent(components.agevex, {
  agents: [main],
  refs: { runTurn: () => internal.agents.runTurn },
  authorize,
  authorizeExecution,
  telemetry: telemetry.slot({
    exporters: [
      langfuse({
        baseUrl: "https://cloud.langfuse.com",
        publicKey: process.env.LANGFUSE_PUBLIC_KEY!,
        secretKey: process.env.LANGFUSE_SECRET_KEY!,
      }),
    ],
  }),
});
```

A propagated fact (subject, thread, run, agent or turn key) over 256 bytes is exported as `sha256:<hex>` of its value instead of being rejected; empty facts are still rejected.

For Braintrust, use `braintrust({ apiKey, projectId })` from the same subpath
instead; it posts to `https://api.braintrust.dev/otel/v1/traces`. The slot gives
each `turnKey` its own bounded buffer, exports it once, then discards it even
on cancellation or failure. Core bounds flush to 3 s and fails open. Stable
run/turn facts produce stable IDs; retries may export duplicates.

## Direct AI SDK setup

For SDK calls outside managed turns, create a fresh buffer per turn and register its integration on the call.
Consume the stream before flushing in `finally`.

```ts title="Register telemetry on an AI SDK call"
import { streamText, type LanguageModel } from "ai";
import { langfuse, telemetry, type Facts } from "agevex/telemetry";

export async function tracedTurn(options: {
  model: LanguageModel;
  prompt: string;
  facts: Facts;
  publicKey: string;
  secretKey: string;
}) {
  const trace = telemetry({
    exporters: [
      langfuse({
        baseUrl: "https://cloud.langfuse.com",
        publicKey: options.publicKey,
        secretKey: options.secretKey,
      }),
    ],
    recordInputs: false,
    recordOutputs: false,
  });
  try {
    const result = streamText({
      model: options.model,
      prompt: options.prompt,
      maxRetries: 0,
      telemetry: { integrations: [trace.integration(options.facts)] },
    });
    await result.consumeStream();
    return await result.text;
  } finally {
    await trace.flush();
  }
}
```

Supply `subject`, `rootThreadId`, `threadId`, `runId`, `agent` and `turnKey`
as nonempty strings in `facts`. Agent 0.7.7 passes unknown `streamText` arguments through unchanged, so `telemetry` reaches the AI SDK. Per-call integrations replace AI SDK
global integrations; AI SDK 7 has no `tracer` option.

## API

- `telemetry(options: TelemetryOptions): TurnTelemetry` — creates a one-turn buffer; `exporters` is required (an empty array is valid).
- `telemetry.slot(options: TelemetryOptions): TelemetrySlot` — creates the registration adapter with isolated buffers per `turnKey`; its `integration(facts)` and `flush(facts, signal?)` implement core's slot contract.
- `integration(facts: Facts): Telemetry` — returns SDK callbacks for `streamText` or `generateText`; validates and copies attribution facts.
- `flush(signal?: AbortSignal): Promise<void>` — seals and drains the buffer once; repeated calls share the same promise.
- `langfuse(options: { baseUrl: string; publicKey: string; secretKey: string }): Exporter` — posts to `<baseUrl>/api/public/otel/v1/traces` using Basic auth and v4 ingestion.
- `braintrust(options: { apiKey: string; projectId: string }): Exporter` — posts to `https://api.braintrust.dev/otel/v1/traces` using Bearer auth and `x-bt-parent: project_id:<projectId>`.

```ts title="Telemetry options and custom exporter contract"
import type { Exporter, Sanitize, TelemetryOptions } from "agevex/telemetry";

const sanitize: Sanitize = (value, attribute) =>
  attribute === "langfuse.user.id" ? undefined : value;

const exporter: Exporter = {
  export(payload, signal) {
    // Send the bounded OTLP payload to your own destination.
    // Return void or a PromiseLike<void>; honor signal when possible.
  },
};

const options: TelemetryOptions = {
  exporters: [exporter],
  recordInputs: false,
  recordOutputs: false,
  sanitize,
};
```

`recordInputs` and `recordOutputs` default to `false`: prompts, instructions,
model output and tool arguments/results are omitted. Set either to `true` to
opt in; SDK recording flags can further disable recording. Raw error diagnostics
are never recorded. User/session/run/agent facts are included on every span by
default; sanitize them when needed.

`sanitize(value, attributeName)` transforms bounded attribute values and dynamic
span name components before buffering. Returning `undefined` omits an attribute;
throwing drops its value and marks truncation. Omitted, empty or rejected name
components become `redacted`. Sanitizer output is bounded again.

Langfuse `baseUrl` is an HTTP(S) host URL, optionally with a deployment path;
credentials in the URL, query strings and fragments are rejected. Braintrust
uses its US endpoint. Invalid configuration or facts throw during setup.

## Limits

`LIMITS` is exported from `agevex/telemetry`. These values are fixed, not
configurable; byte bounds use UTF-8.

| Constant                | Default      | Hard maximum / fixed behavior                                       |
| ----------------------- | ------------ | ------------------------------------------------------------------- |
| `maxSpansPerTurn`       | 128          | 128 across all integrations in the buffer                           |
| `maxAttributeBytes`     | 16,384 bytes | 16 KiB of encoded attributes per span, including JSON escaping      |
| `maxValueBytes`         | 4,096 bytes  | 4 KiB per string/key during traversal and per encoded string value  |
| `maxNameBytes`          | 256 bytes    | 256 per span name and dynamic name component                        |
| `maxFactBytes`          | 256 bytes    | 256 per fact before it is hashed; 256 for the Braintrust project ID |
| `maxConfigurationBytes` | 4,096 bytes  | 4 KiB per Langfuse configuration string and Braintrust API key      |
| `maxExporters`          | 4            | 4 concurrent exporters                                              |
| `maxValueNodes`         | 128          | 128 visited nodes per bounded value traversal                       |
| `maxValueDepth`         | 8            | 8 nesting levels below the traversal root                           |
| `exportTimeoutMs`       | 3,000 ms     | 3 s export deadline, with abort and promise race                    |
| `traceIdHexLength`      | 32           | Fixed 32 hexadecimal characters                                     |
| `spanIdHexLength`       | 16           | Fixed 16 hexadecimal characters                                     |
| `nanosPerMillisecond`   | 1,000,000    | Fixed timestamp conversion factor                                   |

Oversized values use `[truncated]` and `agevex.truncated` markers; excess spans
are dropped while retaining valid ancestry (a call that loses child spans this
way stays OK and its root gets `agevex.truncated`). Empty facts and invalid
configuration strings are rejected rather than truncated; facts over 256 bytes
are hashed. The bounded OTLP request is less
than 2.25 MiB.

## Guarantees

- Stable `runId`, `turnKey` and call order yield deterministic SHA-256 IDs; [integrations](#api) sharing a buffer use distinct span paths.
- Empty buffers and pre-aborted [flushes](#api) send nothing; unfinished spans export as errors.
- Provider errors, interrupted finishes and incomplete streams mark affected spans as errors with safe reasons; see [recording](#api).
- [Export](#api) fails open on network errors, non-2xx responses, exceptions and timeouts; exporters run concurrently with one attempt each.

## Known limits

- The buffer is action-scoped and in memory, with no durable outbox or export retries. Callbacks after flush are ignored.
- Stable IDs do not guarantee exactly-once delivery: action retries can export duplicates, and Langfuse v4 does not guarantee deduplication by ID. Hosts needing exactly-once export must use their own durable outbox.
- The 3 s bound applies to export, not model execution. Synchronous host code, including sanitizers or custom exporters, must return control for cancellation and timers to run.
