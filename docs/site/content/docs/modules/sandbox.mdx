Sandbox provides a persistent filesystem and bounded command tools. Use it when
an agent must execute code or produce files. Its Convex component owns scope
bindings in `sandboxes` and fenced watchdog rows in `jobs`. Host actions
call the provider; commands and file bodies stay outside component rows.

## Wire it into agevex

Install the [built package and peers](/docs/getting-started), plus the Daytona
adapter dependency:

```sh title="Host app"
bun add @daytona/convex@2.1.0
```

Set `DAYTONA_API_KEY` in the host deployment environment. Mount Daytona with
its declared environment binding:

```ts title="convex/convex.config.ts"
import { defineApp } from "convex/server";
import { v } from "convex/values";
import agent from "@convex-dev/agent/convex.config";
import agevex from "agevex/convex.config";
import sandbox from "agevex/sandbox/convex.config";
import daytona from "@daytona/convex/convex.config";

const app = defineApp({ env: { DAYTONA_API_KEY: v.string() } });
app.use(agent, { name: "agent" });
app.use(agevex, { name: "agevex" });
app.use(sandbox, { name: "sandbox" });
app.use(daytona, { env: { DAYTONA_API_KEY: app.env.DAYTONA_API_KEY } });
export default app;
```

The example reuses the single-owner policy from getting started. Scheduled
watchdog calls must recheck persisted ownership without an interactive session.

```ts title="convex/sandboxes.ts"
import {
  defineSandbox,
  daytona,
  sandboxCompletion,
  type PollArgs,
  type PollActionArgs,
  type SettleArgs,
} from "agevex/sandbox";
import type { RegisteredAction, RegisteredMutation } from "convex/server";
import { components, internal } from "./_generated/api.js";
import { runtime } from "./agents.js";

const OWNER_SUBJECT = "replace-with-your-auth-subject";
export const sandbox = defineSandbox({
  component: components.sandbox,
  provider: daytona(components.daytona, { autoStopInterval: 0 }),
  scope: "thread",
  agent: components.agent,
  authorize: async (ctx, scope) => {
    const subject = scope.subject ?? (await ctx.auth.getUserIdentity())?.subject;
    if (subject !== OWNER_SUBJECT) throw new Error("FORBIDDEN");
    return { subject };
  },
  refs: {
    wake: () => internal.sandboxes.wake,
    poll: () => internal.sandboxes.poll,
    settle: () => internal.sandboxes.settle,
    cleanup: () => internal.sandboxes.cleanup,
  },
  onComplete: sandboxCompletion(() => runtime),
});
const functions = sandbox.internalFunctions();
export const wake: RegisteredMutation<"internal", PollArgs, null> = functions.wake;
export const poll: RegisteredAction<"internal", PollActionArgs, null> = functions.poll;
export const settle: RegisteredMutation<"internal", SettleArgs, null> = functions.settle;
export const cleanup: RegisteredAction<"internal", Record<string, never>, null> = functions.cleanup;
```

Set `sandbox: true` on each Agent that should receive sandbox tools in
`agentConfig.ts`. Replace `convex/agents.ts` with:

```ts title="convex/agents.ts"
import { registerAgent } from "agevex";
import { components } from "./_generated/api.js";
import { registration } from "./agentConfig.js";
import { sandbox } from "./sandboxes.js";

export const runtime = registerAgent(components.agevex, {
  ...registration,
  sandbox: sandbox.slot(),
});
export const { runTurn, coordinate, textTask } = runtime.internalFunctions();
export const {
  open,
  send,
  cancel,
  respond,
  answer,
  messages,
  streams,
  activity,
  runTree,
  delegations,
} = runtime.authorizedEndpoints();
```

Core supplies the root thread to the slot, so children share the conversation's
filesystem. `sandboxCompletion` posts a bounded passive note to that root
atomically with terminal job state. A note waits for a safe turn claim.

## Effects and tools

The slot offers `sandbox_exec`, `sandbox_read_file`, `sandbox_write_file`,
`sandbox_list` and `sandbox_run_background`. Effects use core once-tool
receipts. Pure reads require a trusted ToolContext. Models never supply owner,
provider sandbox id or sharing scope.

`scope` is `thread`, `run` or `subject`; keys always include the
subject. Background admission persists identity, reconciliation location and a
finite watchdog before launch. Unknown commands never replay. Safe status reads
can retry until the deadline. A callback error rolls back terminal settlement;
watchdog attempts are finite. Unknown snapshots remain readable through `job`.

A definite `FORBIDDEN` or `SANDBOX_FORBIDDEN` policy refusal stops provider
access; other policy errors are treated as transient until the deadline.
`cleanup` is explicitly host-driven; mounting installs no timer.

## Exports and recovery

`export(ctx, { threadId, path })` authorizes an existing binding, downloads
bounded windows, hashes the bytes and stores a native Agent file. It returns
`SandboxExportResult`. Supply `agent` for exports and a trusted
`resolveThread` for run-scoped exports. For larger files, export
`sandboxNodeExport(options)` from a host `"use node"` file and register its
reference as `nodeExport`.

An uncertain delete stays reconcilable. `forget` clears only a lost create
with no known provider id. First find and delete the possible provider sandbox
using its `agevexScope` label / `userKey`; forgetting is not provider cleanup.

## Limits

| Bound                       | Default                 | Hard maximum                   |
| --------------------------- | ----------------------- | ------------------------------ |
| Command deadline            | 180 seconds             | 180 seconds                    |
| Combined stdout/stderr tail | 6,000 characters        | 12,000                         |
| Completion log tail         | 3,000 characters        | Fixed                          |
| Read / write text           | 160,000 characters each | Same                           |
| Directory entries           | 100                     | 100                            |
| Binary export               | 8 MiB                   | 8 MiB; 64 MiB with Node export |
| Download window             | 512 KiB                 | Fixed                          |
| Jobs per sandbox            | 16                      | 64                             |
| Job deadline                | 1 hour                  | 24 hours                       |
| Idle TTL                    | 24 hours                | 365 days                       |
| Cleanup batch               | 32                      | 64                             |

Provider snapshots need `python3`. Daytona auto-stop defaults to 15 minutes,
auto-archive to 10; set auto-stop to zero for long jobs. Cleanup kills descendants
in the original process group. Deliberately detached processes require sandbox
stop/delete. See the
[module README](https://github.com/pixelscortex/agevex/blob/HEAD/src/modules/sandbox/README.md).
