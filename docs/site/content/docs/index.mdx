agevex is a headless Convex component and host client. Native Agent owns threads,
messages and streams. agevex adds Workflow coordination, bounded turns,
delegation, cancellation fences and receipts.

The host owns authorization, model selection, pricing and domain tools. Optional
modules add [metering](/docs/modules/meter), [sandboxes](/docs/modules/sandbox),
[file extraction](/docs/modules/extract), [telemetry](/docs/modules/telemetry)
and [tools](/docs/modules/tools). Core imports none of those modules.

## Start here

1. [Mount and register](/docs/getting-started) one agent.
2. Read the [architecture](/docs/concepts/architecture) for ownership and turn flow.
3. Add [delegation](/docs/concepts/delegation) or a module when needed.
4. Run [offline tests](/docs/testing) before connecting paid providers.

These pages describe implemented exports. The package is currently private and
has no npm release. Pin the repository revision you consume. agevex ships no UI;
use the native transcript and streams to build your own.
