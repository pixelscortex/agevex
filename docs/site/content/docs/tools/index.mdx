Import [ask_user](/docs/tools/ask-user) from `agevex/tools`. It asks a bounded
question or structured form and waits for core `answer`, without extra tables.

[Asking the user to raise a budget](/docs/tools/raise-budget) composes this tool
with the core budget hook and the host's own spending policy.

Delegated children also get the core `agevex_ask_parent` tool. See
[delegation](/docs/concepts/delegation) for parent questions and child messaging.
